# Handoff template

Copy to `docs/reports/<TASK-ID>-<short-result>.md`. Replace every placeholder; never fill evidence with invented output.

## Task and baseline
Task ID; role; date; repository/branch; starting SHA; Figma file/node IDs read before writing. Scope actually performed.

## Result
Changed paths/nodes and their purpose. Link to commit/PR and stable Figma node URLs. What remains unchanged.

## Verification
For every check: exact command or inspection method; input fixture; actual result; evidence file/link; PASS / FAIL / NOT RUN. Include device/browser/build version for runtime tests. A simulator or mocked MIDI stream is not a physical-device test.

## Remaining risks / blockers
Concrete failure or uncertainty, impact, what was tried, proposed smallest next action. List skipped checks explicitly.

## Review
Reviewer identity/role, independent checks, findings, verdict. Owner approvals separately: scope, date, evidence. No approval inferred from silence.

## Continuation
Current task status. Next eligible task ID and why. Only unresolved context needed by the next agent. Do not paste secrets, imported user music or personal recordings.
