# Эталонный маршрут alpha: «Первый мотив»

## Почему не Another Love
Пользователь хочет Another Love, но конкретная аранжировка и права не установлены. Скриншоты и случайные аккорды из чата не годятся как dataset. Для разработки используем короткое оригинальное учебное упражнение. Оно не называется кавером, транскрипцией или упрощением Another Love. KF-022 создаёт файл и golden events; сейчас здесь спецификация, не готовый музыкальный asset.

## Точный музыкальный материал
Название: «Первый мотив» / First Motif. Одна партия piano, два staff, 8 тактов 4/4; quarter=60; C major; без repeat signs, pedal, grace notes и ties в основной учебной версии. Middle C = C4 = MIDI60. Длительности ниже в четвертях; сумма каждой руки в такте — 4.

| Такт | Правая рука (pitch:duration) | Левая рука | Учебная гармония |
|---|---|---|---|
| 1 | C4:1, D4:1, E4:1, G4:1 | C3:4 | C |
| 2 | E4:2, D4:1, C4:1 | C3:4 | C |
| 3 | E4:1, G4:1, A4:1, G4:1 | A2:4 | Am |
| 4 | E4:2, C4:2 | A2:4 | Am |
| 5 | F4:1, A4:1, G4:1, F4:1 | F2:4 | F |
| 6 | E4:1, G4:1, D4:1, G4:1 | G2:4 | G |
| 7 | E4:1, D4:1, C4:1, D4:1 | G2:4 | G |
| 8 | C4:4 | C3:4 | C |

26 RH note events + 8 LH events = 34 attacks; total 32 quarter units. At quarter=60 and speed=1, score duration=32 s excluding count-in. Phrase A bars1–2 lasts8 s; at speed0.5 lasts16 s. Use these as executable golden assertions. Harmonic labels are editorial context, not the name of every simultaneous note pair.

Диапазон полного упражнения F2–A4. В onboarding не предполагать 88 клавиш. Первые два такта требуют только C3–G4; при нехватке диапазона предложить этот фрагмент и объяснить ограничение, не транспонировать молча.

## Путь новичка: 10 шагов
1. Ориентир: найти группу двух чёрных клавиш и C4. Крупная схема + «Послушать». Нет автоматического успеха от проигрывания.
2. Найти C4/D4/E4/G4 по одной. В экранном режиме проверяем только выбор на экране; на реальном инструменте без MIDI — self-report.
3. Увидеть те же ноты на скрипичном стане и нажать «Показать клавиши». Notation остаётся настоящей, не Unicode-имитацией нот.
4. Четыре доли: пример из такта1, медленный metronome; пользователь проговаривает/играет, сам оценивает.
5. RH такт1 при speed0.5. Предложенная аппликатура 1/2/3/5 — редакторская подсказка для данного упражнения, не автоматическое вычисление.
6. RH такт2: E4 удержать две доли, затем D4/C4. Показать длительность, не повторять E4 на второй доле.
7. Переход конца такта1 к началу такта2; loop A/B на границах тактов. Предложить 3 попытки, не запирать продолжение.
8. LH C3 целая нота, затем повтор в следующем такте. Явно различить удержание4 доли и 4 нажатия.
9. Соединить обе руки bars1–2. Подсказка ведущей руки, счёт перед началом; при трудности вернуться к шагу5 или8.
10. Контрольная попытка bars1–2 с reduced hints → reflection → сохранить место → повторить позже либо изучить bars3–4.

После первой фразы оставшиеся пары тактов используют тот же pattern с новым материалом. Отдельный complete-piece результат появляется после согласованного прохождения всех фраз; прохождение первого урока не означает освоение всех8 тактов.

## Эталонная демонстрация UX
Открыть → выбрать учебный пример → шаг1 → послушать → попробовать → теория по нажатию → вернуться → потренировать RH → LH → вместе → self-report → закрыть → открыть offline подготовленный урок → продолжить.

В Figma музыка и feedback для демонстрации имеют label «Пример». В live app учебный файл исполняется реально; состояние success не таймерная анимация. User testing записывает, на каком шаге новичок потерялся, а не только факт прохождения экрана.
