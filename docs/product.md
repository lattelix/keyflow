# Product specification — Keyflow v0.4 teaching alpha

## Обещание и границы
Открыть приложение → понять следующую задачу → услышать пример → увидеть соответствие звука, клавиш и нот → попробовать на своём инструменте → разобрать трудность → вернуться к фрагменту → сохранить результат. Один законченный учебный маршрут обязателен уже в alpha.

Нельзя обещать «любая песня автоматически превращается в курс» или «с нуля до профессионала без учителя». Такие возможности не следуют из наличия нотного файла. Любимая музыка — мотиватор; progression проверяется отдельно от времени в приложении.

## Пользовательские режимы
1. **Без подключения**: акустическое/цифровое пианино рядом; приложение показывает и воспроизводит пример, пользователь отвечает о своей попытке. Label: «Самооценка · приложение не слышит вашу игру».
2. **Экранные клавиши**: упражнение по распознаванию нот внутри UI. Label: «Практика на экране»; не считать измерением игры на пианино.
3. **MIDI**: после отдельного этапа и проверки capability — объективные события нот и времени. Label: «Проверка по MIDI». Это не оценка пальцев/посадки/выразительности.

Выбор устройства не вызывает permission prompt, регистрацию или покупку. Возможность можно подключить позже. Неподдерживаемая функция объясняется и имеет working fallback.

## Информационная архитектура
Четыре основных раздела: **Главная / Музыка / Учиться / Библиотека**. Progress доступен с Главной; Settings — из постоянной кнопки. Practice открывается как сфокусированное рабочее пространство, без marketplace/navigation clutter. Экранные ID и точные действия — `design/screens.json`.

В alpha «Музыка» ищет по включённому учебному набору и локальным импортам. Это не поиск по интернету и не каталог всех популярных композиций. Пустой поиск: «Такой музыки пока нет в вашей библиотеке» + «Импортировать файл» + «Открыть учебный пример».

## User stories и acceptance
- Новый пользователь без знания notation запускает первый урок без аккаунта и видит одну главную CTA.
- Вернувшийся пользователь одним действием продолжает последний сохранённый шаг с тем же фрагментом и настройками.
- Пользователь понимает, почему урок необходим для фрагмента, и может временно пропустить его, не получая ложную отметку освоения.
- Пользователь замедляет фрагмент, выбирает руку, зацикливает такты, слушает пример и пробует отдельно.
- Пользователь открывает объяснение символа и возвращается в то же место; показ помощи не сбрасывает урок.
- Пользователь видит, что именно измерено, а что оценил сам; завершение playback не означает успешную попытку.
- Пользователь экспортирует/восстанавливает свои данные и узнаёт о рисках удаления browser storage.
- Пользователь заранее сохраняет урок offline; статус «готово» появляется только после фактической подготовки всех ресурсов.

Формализованные требования — `requirements.json`; тесты — `qa/acceptance.md`.

## Минимальные данные произведения
Различать Work (произведение), Arrangement (конкретная версия/аранжировка) и ScoreSource (файл). У аранжировки есть автор/источник, права, версия, уровень, диапазон, поддерживаемые возможности и учебный маршрут, если он подготовлен. «Оригинальная версия» допустима только с подтверждённым источником; пользовательская транскрипция не становится оригиналом по названию песни.

Разделы Intro/Verse/Chorus не выводятся из номера такта автоматически. Без разметки показывать «Фрагмент 1», диапазон тактов и ручное выделение. Chord names/fingering либо из данных/редакторской разметки, либо явно обозначенная непроверенная гипотеза (не alpha).

## Следующее действие
Для authored route алгоритм: просроченное короткое повторение уже начатого навыка → незавершённый prerequisite текущей фразы → выбранная фраза одной рукой → вместе → соединение соседних фраз → контрольная попытка без лишних подсказок. Пользователь может выбрать другой шаг. Нельзя запирать музыку за искусственным уровнем.

У self-report нет процентов точности. Прогресс — «пройдено 3 из 10 шагов», «практиковал», «стоит повторить». Время работы, количество повторов и confidence не равны mastery. Для MIDI метрики показываются с basis/tempo/range и правилами matching.

## Non-goals alpha
Нет обязательных облачных аккаунтов, социальных функций, магазина, микрофона, камеры, автоматического audio-to-score/PDF-OCR, сервиса подписок, generative AI API, полного нотного редактора, автоматического удаления/замены user files. Native desktop — отдельное решение.
