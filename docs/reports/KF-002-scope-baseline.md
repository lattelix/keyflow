## Нормативный baseline для дизайна v0.2
**Кто:** новичок, умеющий назвать несколько нот, но не обязанный читать нотный стан; интерфейс по умолчанию русский, English locale отдельно.

**Первые 30 секунд:** пользователь может начать оригинальный учебный пример без регистрации, разрешений устройств или выбора подписки; во всех состояниях ему понятно одно конкретное следующее действие.

**Главный цикл:** выбрать произведение / оригинальный пример → увидеть полезные предпосылки → короткое объяснение → прослушать → попробовать с клавишной/нотной подсказкой → оценить попытку (либо получить evidence в поддерживаемом режиме) → разобрать слабый фрагмент по рукам/переходам → объединить → сохранить позицию → вернуться.

**Объём первого полезного alpha:** одна полностью authored учебная дорожка на собственном проверенном материале «Первый мотив». 8 тактов `4/4`, 60 quarter BPM, C major; 10 подробных шагов ведут через первые два такта, следующие музыкальные фразы — после них и не подменяют достижение полного произведения. Проверяемые pitch/duration/count значения из `reference-journey.md`. Ресурсы импортов могут быть practice-only без автоматически сгенерированного курса.

**Информационная архитектура:** четыре основных пункта «Главная», «Музыка», «Учиться», «Библиотека»; из Главной доступен Progress, Settings доступен из shell. Practice — отдельный focus workspace. Нет внешнего магазина нот или обязательного онлайн-поиска.

**Устройства:** web/PWA как самостоятельный первый полезный продукт; phone compact/landscape, tablet digital stand, desktop/web, светлая/тёмная темы и RU/EN. Данные, смысл действий и компоненты унифицированы; native iOS/Android — после собственного разрешения. Вход без обязательного аккаунта.

**Evidence в alpha:** self-report «Получилось уверенно» / «Нужно повторить» / «Слишком сложно» не содержит % точности или подтверждения физической техники. Экранные ноты проверяют только on-screen choice. MIDI измерения только после отдельного этапа и доказанной реальной input capability. Отсутствие подключения — работоспособный сценарий, а не блокировка урока.

**Учебный прогресс:** авторское прохождение и самооценка, не «профессиональный уровень». Пропуск не считается освоением, просмотр/звучание не считается успешной попыткой. Слишком сложная задача → уменьшить фрагмент, выбрать руку, замедлить, показать подсказку, затем дать вернуться к исходной цели.

**Хранение:** все данные локально, точный resume урок/фрагмент/темп/руки/подсказки, backup/export/restore после explicit confirm, подготовленный offline урок проверяется по ресурсам. Ошибка хранения не показывается как success.

## Из alpha исключено
Автогенерация курса из любого файла; internet catalog/скрейпинг MuseScore или YouTube; платные SDK/AI API; регистрация, облачный backend/sync; микрофон/камера и автоматическая audio-to-score/PDF транскрипция; оценка пальцев/посадки из MIDI; магазин/домены/платное распространение/production без approval; полное обещание «с нуля до профи»; native desktop или App Store/Google Play релиз до отдельного этапа.

`Another Love — Tom Odell` остаётся мотивацией и UX-reference, но не bundled файлом, партитурой «оригинальной версии» или проверенной гармонией. Rights code ≠ rights score/audio/video/fonts.
