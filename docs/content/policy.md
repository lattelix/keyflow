# Контент, источники и лицензии

## Разделять права
Права на код не предоставляют права на партитуры, аранжировки, аудио, видео, обложки или sample bank. Публичный repository без LICENSE не становится автоматически open source. Для нового кода/документации предложена MIT (DEC-013); владелец подтверждает до public release. Не приписывать её чужим assets.

## Разрешённый bundled dataset
Оригинальные упражнения проекта; материалы с конкретной разрешающей распространение лицензией; public-domain произведение **и отдельно** разрешённая редакция/аранжировка/запись. Для каждого файла manifest содержит assetId, type, title, creator, source, license, attribution, checksum, verificationDate, approvedForRedistribution. Нет записи или прав — файл не идёт в bundle.

В этой версии документации партитуры/записи не добавляются. KF-022 создаёт First Motif и тестовые fixtures, а reviewer сверяет их со спецификацией. Проверка лицензии sample bank — обязательна до выбора piano sound. Если нет разрешённых samples, разрешён временный synth с честным названием «синтезированный тембр», не «реалистичный рояль».

## Пользовательский импорт
Файл остаётся в памяти/локальном хранилище устройства. Не коммитить, не отправлять на сервер/LLM, не включать в telemetry, backup examples или screenshots public PR. UI предупреждает о правах при публичном распространении, но не утверждает юридический статус пользовательского файла.

Не загружать внешний URL из score автоматически. Credit text экранируется как текст. Медиавложения, remote images и исполняемые SVG/HTML не поддерживаются в import.

## Another Love
Можно использовать название как желаемую пользователем цель и внешнюю ссылку на легальный источник, когда она проверена. Нельзя считать пользовательскую транскрипцию оригинальным piano accompaniment, придумывать аккорды или переносить screenshot в public fixture. Конкретный arrangement должен иметь источник и version.

## Видео/аппликатура
В alpha допускаются curated внешние ссылки с названием, длительностью, автором и причиной просмотра; не download/cache чужое видео. Пользователь явно открывает ссылку вне practice, playback предварительно останавливается. Offline отсутствие видео объясняется; основной урок должен работать без него. Аппликатура хранит источник и статус editorial_reviewed.

## Release checklist
Проверены зависимости и license notices; есть root LICENSE по решению owner; отдельный CONTENT_LICENSES/manifest; samples/fonts/video links проверены; user data отсутствуют в public repo. При неизвестных правах блокируется соответствующий контент, а не подменяется неизвестной копией.
